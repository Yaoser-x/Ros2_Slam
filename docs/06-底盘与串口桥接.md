# 底盘与串口桥接

运行时只支持 Upper Protocol v3；协议见
[Upper Protocol v3](./interfaces/upper-protocol-v3.md)。候选固件为
`158254bd5c21f74a64f1d7c8609475a4c7caa1c7`，尚未成为 compatible commit。

Bridge 负责串口、frame/codec、HELLO/capability、wire session、sequence/ACK、
STATUS/command timeout 和 ROS 状态适配。它发布原始 `WheelObservation`、
`ImuObservation`、链路/固件状态与 diagnostics，不计算里程计、不发布 TF，也不拥有
运动监督或导航。

```bash
./bin/robot base
./bin/robot base-test --rotate-only
# 车辆架空、驱动轮自由转动且有人可急停时使用：
./bin/robot base-test --suspended-wheel
./bin/robot check chassis
```

默认底盘端口为 `/dev/serial0`、115200 8N1。Bridge 在 HELLO、能力、当前 session
STATUS 和精确 received/applied ACK 满足前保持 fail-closed。duplicate 幂等忽略，
old session/out-of-order 拒绝且不改变当前目标；当前活动 epoch 的完整性错误、
STATUS/ACK timeout、ESTOP/fault、firmware reject 或断线会 release 并要求双层 rearm。

公共底盘操作使用 `/chassis/operation` Action。Bridge 私有 `wire_*` service 只证明
请求进入队列；LINE_CONTROL、CLEAR_FAULT 因协议没有请求关联的 applied 证据返回 `QUEUED`，其他操作按
新 STATUS/HELLO 返回 `APPLIED`、`REJECTED`、`TIMEOUT` 等结果。

当前配对绑定硬件 revision `0x20000` 和实读参数 CRC `0x0D663E2A`，轮距为
178 mm、轮半径 35 mm、编码器每转 2464 count；标定仍为 provisional。
完整车辆与发布证据尚未收齐，`release_compatible` 保持 false。

`--suspended-wheel` 仅允许真实串口和 wheel-only 里程计；它先连续静止观察
30 秒，再执行前后各 0.05 m/s × 2 秒、左右各 0.20 rad/s × 2 秒、
0.05 m/s × 12 秒和 0.01 m/s → 0。每段间停车，要求目标与输出均为零、
轮速绝对值不超过 5 mm/s，且三帧不同序号的编码器计数静止，限时 0.8 秒。
轮速超过 0.15 m/s、输出超过 40%、反向反馈、故障或观测过期会立即中止。
命令和原始 ROS 消息写入 JSONL，结果和有效配置清单写入 JSON；进程故障、
PS2、IMU 宏、长稳和断电项目另行记录，未执行时保留 NOT_RUN。
架空转向只验证差速、反馈和里程计符号，不用于真实转角标定。

Bridge 退出时拒收新请求并丢弃待发旧运动，由唯一串口线程优先发送新 disable，
最多等待 200 ms。`shutdown_disable_written` 仅表示完整帧写入串口；
下位机 APPLIED 与实际停车必须由独立接收和轮观测确认。
